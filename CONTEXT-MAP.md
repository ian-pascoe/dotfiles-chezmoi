# Context Map

Read the domain context relevant to the source area being changed.

- **Pi agent configuration**
  - Scope: Pi settings, extensions, and runtime behavior under `dot_pi/agent/`.
  - Context: `dot_pi/agent/CONTEXT.md`
- **Oh My Pi configuration**
  - Scope: Oh My Pi settings and extensions under `dot_omp/agent/`.
  - Context: `dot_omp/agent/CONTEXT.md`
- **OpenCode configuration**
  - Scope: OpenCode settings, prompts, commands, and plugins under
    `dot_config/opencode/`.
  - Context: `dot_config/opencode/CONTEXT.md`

For changes spanning contexts, read every affected context. Cross-context architectural
decisions live in `docs/adr/`.
