# Title: OpenCode Ast-Grep and LSP Plugin Implementation

This document captures the OpenCode plugin workstream across implementation, config precedence, refactor details, and review outcomes.

## Timeline narrative
- The ast-grep plugin was refactored from five top-level tools into one operation-based `ast_grep` tool with nested operations.
- An LSP override plugin named `lsp` was added with diagnostics, code-action, and formatting capabilities.
- The plugin should reuse the existing opencode LSP config for configuration options.
- Merged runtime config can report `lsp: false`, so discovery must fall back to `/global/config` to recover user-defined LSP servers such as `biome`.
- Independent review later found a medium-severity multi-server compatibility regression in workspaceSymbol server selection, specifically that filePath/file-based server resolution must be preserved.
- Subsequent spec-compliance and final re-review status notes indicate approval of the async cleanup fix and ast-grep consolidation, with only limited residual runtime-smoke-test caveats noted in the review history.

## Implementation details
- ast_grep operations include search, replace, scan, ruleTest, and debugPattern.
- The LSP plugin exposes diagnostics, codeActions, applyCodeAction, renameSymbol, formatDocument, organizeImports, and fixAll.
- LSP runtime dependencies include vscode-jsonrpc and vscode-languageserver-protocol.
- The OpenCode implementation was done in-place on main without a worktree.
- Verification passed via test, typecheck, lint, and format checks.

## Review and deployment
- The work received spec approval, code quality approval, and final runtime diff review approval in the implementation record.
- One review later recorded a medium-severity workspaceSymbol regression in multi-server setups.
- The ast-grep re-review approved the fix and noted only residual risk from mocked-only integration coverage.
- Deployment guidance: run chezmoi apply and restart OpenCode.

## Facts
- The ast-grep plugin uses one dispatch-based tool instead of five top-level tools.
- LSP discovery must distinguish merged runtime config from global config.
- workspaceSymbol must resolve filePath/file when selecting a client.
- Verification commands passed for the dot_config/opencode workspace.
- OpenCode restart is required after applying the source change.
