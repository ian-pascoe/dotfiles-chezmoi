# Domain: facts

## Purpose
Contains operational curation workflows, constraints, and durable process rules for context engineering.

## Scope
Included in this domain:
- RLM curation procedures
- verification rules
- workflow constraints
- context-engineering process guidance

Excluded from this domain:
- Product feature documentation
- implementation source code
- general project notes unrelated to curation

## Usage
Use this domain for durable instructions about curation workflows and process rules.
